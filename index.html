projeto — 02

MotoTracker — Painel Admin

Interface web de gerenciamento completo do ecossistema MotoTracker — construída do zero em HTML, CSS e JavaScript vanilla, sem frameworks. O painel concentra toda a operação do produto: gestão de usuários e assinaturas, acompanhamento de MRR e funil de conversão, disparo de notificações push em massa, automação de e-mails, emissão de cupons promocionais, gerenciamento de suporte e ferramentas internas como impersonação de usuário e publicação de novas versões do app. Deploy na Vercel com acesso restrito por autenticação JWT via API Flask.

HTML CSS JavaScript Chart.js Flask JWT Vercel
